# Workshop schedule

| Time | Min | Block | What happens |
|---|---:|---|---|
| 10:00 | 20 | **Welcome and tool choice** | Meet the case, tour the interface, and watch a short Deep Research demonstration. |
| 10:20 | 30 | **Foundation lab** | Connect sources, claims, evidence, and clear test criteria. |
| 10:50 | 10 | **Break** | |
| 11:00 | 35 | **Notebook core** | Compare multi-page evidence documents and derive the decision. |
| 11:35 | 30 | **Notebook flex** | Finish the core or choose Citation Detective or Decision Under Pressure. |
| 12:05 | 45 | **Lunch** | |
| 12:50 | 20 | **Chat agent demonstration** | Build a bounded agent and test it against expected results. |
| 13:10 | 25 | **Chat agent core** | Build, restrict, test, and repair the agent. |
| 13:35 | 25 | **Chat agent flex** | Run a binary evaluation or adversarial tests. |
| 14:00 | 10 | **Break** | |
| 14:10 | 20 | **Workflow demonstration** | See a structured review with human escalation. |
| 14:30 | 40 | **Workflow core** | Review an incomplete package and report missing evidence. |
| 15:10 | 20 | **Workflow flex** | Test the complete or conflicting package. |
| 15:30 | 15 | **Compare core** | Compare results against the same criteria. |
| 15:45 | 15 | **Wrap-up** | Share one finding, one failed test, and one use case of your own. |

**Total workshop time: 360 minutes. Breaks and lunch: 65 minutes. Learning time: 295 minutes.** The shared core establishes the foundations; flex blocks give faster participants meaningful additional depth.
