# Module 1: Gemini Notebook

You examine four multi-section documents in the P-17 evidence set. The decisive information is distributed across sections and documents. Notebook helps combine the material; verifying the sources remains your responsibility.

## Learning goals

By the end of this module, you can:

- create a deliberately bounded document collection;
- distinguish preliminary figures from final verified figures;
- combine several documents into a decision;
- open supporting passages and check them against a claim;
- leave missing information explicitly unresolved.

## Source files

The `Files` folder contains four synthetic PDFs. The identical complete text copies are in `workshop-data/cloud-storage`. The first section does not reveal the final answer. Use exactly one representation of each document and do not add web or external sources.

## What good work looks like

The answer distinguishes early dashboards from verified results, includes the pilot and independent repeat, applies the 85% rule, and does not invent a retention period.
