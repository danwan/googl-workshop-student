# Module 0: Gemini Enterprise foundations

This shared opening module gives everyone the same orientation. You identify the available tools, verify one documented rule, and test one deliberately undocumented fact.

## Learning goals

By the end of this module, you can:

- distinguish Gemini Notebook, Deep Research, Chat agent, and Workflow;
- ask a question against a bounded knowledge base;
- open a supporting passage and compare it with an answer;
- recognize a missing fact as a correct test result;
- explain why plausible but unsupported writing fails.

## Choose your path

| Lab | Level | Time | Observable result |
|---|---|---:|---|
| [0.1 Interface and source checks](./lab-0.1-interface-and-grounding.md) | Guided | 25-30 min | One verified P-17 rule and one safely handled information gap |

This module is the same for everyone. Tiered difficulty begins in Module 1.

## What good work looks like

You can explain the tool choice, open the source behind the P-17 rule, and explain why “not documented” is better than an invented retention period.
